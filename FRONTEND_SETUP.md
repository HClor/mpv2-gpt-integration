## 1. Импорт элементов в MODX

### 1.1 Создание шаблона

1. Перейдите в **MODX Manager → Элементы → Шаблоны**
2. Нажмите "Создать новый шаблон"
3. Название: `LMS Bootstrap 5`
4. Скопируйте содержимое из файла: `core/elements/templates/LMS_Bootstrap_5.tpl`
5. Сохраните

### 1.2 Создание чанков

Перейдите в **MODX Manager → Элементы → Чанки** и создайте следующие чанки:

| Название чанка | Файл источника | Описание |
|----------------|----------------|----------|
| `lmsHeader` | `core/elements/chunks/lmsHeader.tpl` | Шапка для LMS страниц |
| `menuItemTpl` | `core/elements/chunks/menuItemTpl.tpl` | Пункт меню |
| `menuOuterTpl` | `core/elements/chunks/menuOuterTpl.tpl` | Обертка меню |

### 1.3 Создание сниппетов

Перейдите в **MODX Manager → Элементы → Сниппеты** и создайте следующие сниппеты:

#### Основные сниппеты системы:

| Название сниппета | Файл источника | Описание |
|-------------------|----------------|----------|
| `testRunner` | `core/elements/snippets/testRunner.php` | Запуск и прохождение тестов |
| `myTests` | `core/elements/snippets/myTests.php` | Управление моими тестами |
| `myFavorites` | `core/elements/snippets/myFavorites.php` | Избранные вопросы |
| `knowledgeAreasManager` | `core/elements/snippets/knowledgeAreasManager.php` | Управление областями знаний |
| `authHandler` | `core/elements/snippets/authHandler.php` | Обработчик авторизации |
| `userMenu` | `core/elements/snippets/userMenu.php` | Меню пользователя |
| `userProfile` | `core/elements/snippets/userProfile.php` | Профиль пользователя |
| `leaderboard` | `core/elements/snippets/leaderboard.php` | Рейтинг пользователей |
| `csvImportForm` | `core/elements/snippets/csvImportForm.php` | Импорт вопросов из CSV |
| `addTestForm` | `core/elements/snippets/addTestForm.php` | Форма создания теста |

#### Вспомогательные сниппеты:

| Название сниппета | Файл источника | Описание |
|-------------------|----------------|----------|
| `MenuWithACL` | `core/elements/snippets/MenuWithACL.php` | Меню с проверкой прав |
| `Year` | `core/elements/snippets/Year.php` | Вывод текущего года |
| `pdoCrumbs` | `core/elements/snippets/pdoCrumbs.php` | Хлебные крошки |

## 2. Создание групп пользователей

### 2.1 Создайте группы пользователей

1. Перейдите в **MODX Manager → Безопасность → Группы доступа**
2. Создайте следующие группы:

#### Группа "LMS Admins"
- Название: `LMS Admins`
- Описание: Администраторы LMS системы
- Права: полный доступ ко всем функциям

#### Группа "LMS Experts"
- Название: `LMS Experts`
- Описание: Эксперты/Преподаватели, могут создавать тесты
- Права: создание и редактирование тестов

#### Группа "LMS Students"
- Название: `LMS Students`
- Описание: Студенты, могут проходить тесты
- Права: прохождение тестов, просмотр статистики

## 3. Структура ресурсов

### 3.1 Создайте структуру страниц

Перейдите в **MODX Manager → Ресурсы** и создайте следующую структуру:

```
📂 Главная (ID: 1)
├── 📄 Вход (ID: 24)
│   └── Контент: [[!authHandler]]
│   └── Шаблон: LMS Bootstrap 5
│
├── 📄 Профиль (ID: 28)
│   └── Контент: [[!userProfile]]
│   └── Шаблон: LMS Bootstrap 5
│   └── Права: только для авторизованных
│
├── 📄 Рейтинг (ID: 34)
│   └── Контент: [[!leaderboard]]
│   └── Шаблон: LMS Bootstrap 5
│
├── 📄 Избранное (ID: 115)
│   └── Контент: [[!myFavorites]]
│   └── Шаблон: LMS Bootstrap 5
│   └── Права: только для авторизованных
│
├── 📂 Тесты (ID: 35)
│   ├── 📂 Категория 1 (ID: создается автоматически)
│   │   └── 📄 Тест 1 (создается через систему)
│   │       └── Контент: [[!testRunner]]
│   └── 📂 Категория 2
│       └── 📄 Тест 2
│
├── 📄 Мои тесты (ID: 36 или другой)
│   └── Контент: [[!myTests]]
│   └── Шаблон: LMS Bootstrap 5
│   └── Права: только для авторизованных
│
├── 📄 Области знаний (ID: 125)
│   └── Контент: [[!knowledgeAreasManager]]
│   └── Шаблон: LMS Bootstrap 5
│   └── Права: только для авторизованных
│
└── 📄 Тестовая страница области (ID: 145)
    └── Контент: [[!testRunner]]
    └── Шаблон: LMS Bootstrap 5
    └── Права: только для авторизованных
```

### 3.2 Важные ID страниц

После создания ресурсов, запишите их ID:

- **Страница авторизации**: ID = 24 (или ваш ID)
- **Профиль**: ID = 28
- **Рейтинг**: ID = 34
- **Избранное**: ID = 115
- **Мои тесты**: ID = 36
- **Области знаний**: ID = 125
- **Тестовая страница области**: ID = 145
- **Папка "Тесты"**: ID = 35 (или ваш ID)

## 4. Настройка системных настроек

### 4.1 Настройки MODX

Перейдите в **MODX Manager → Система → Системные настройки** и установите:

1. **Создайте новые системные настройки:**

| Ключ | Значение | Описание |
|------|----------|----------|
| `lms.auth_page` | `24` | ID страницы авторизации |
| `lms.user_tests_folder` | `129` | ID папки для пользовательских тестов |
| `lms.test_template` | `ID вашего LMS шаблона` | ID шаблона для тестов |

### 4.2 Создание системных настроек

1. Перейдите **Система → Системные настройки**
2. Нажмите "Создать новый параметр"
3. Для каждого параметра из таблицы выше:
   - Ключ: укажите ключ (например: `lms.auth_page`)
   - Значение: укажите значение
   - Пространство имен: `core`
   - Область: `Site`

## 5. Проверка работоспособности

### 5.1 Проверьте права на файлы

```bash
# В корне проекта выполните:
chmod -R 755 assets/components/testsystem/
chmod -R 755 core/components/testsystem/
```

### 5.2 Тестирование функционала

#### Шаг 1: Регистрация и авторизация
1. Откройте страницу авторизации (ID: 24)
2. Создайте тестового пользователя
3. Войдите в систему
4. Убедитесь что меню пользователя отображается

#### Шаг 2: Создание теста
1. Добавьте пользователя в группу "LMS Experts" или "LMS Admins"
2. Откройте страницу "Мои тесты"
3. Нажмите "Создать тест"
4. Заполните форму и создайте тест
5. Убедитесь что тест создан

#### Шаг 3: Добавление вопросов
1. Откройте созданный тест
2. Нажмите "Добавить вопрос"
3. Заполните вопрос и варианты ответов
4. Сохраните вопрос

#### Шаг 4: Прохождение теста
1. Откройте страницу теста
2. Нажмите "Начать тест"
3. Ответьте на вопросы
4. Завершите тест
5. Проверьте результаты

#### Шаг 5: Области знаний
1. Откройте страницу "Области знаний" (ID: 125)
2. Нажмите "Создать область"
3. Выберите несколько тестов
4. Создайте область
5. Запустите тестирование по области

#### Шаг 6: Избранное
1. Во время прохождения теста нажмите на звездочку у вопроса
2. Откройте страницу "Избранное" (ID: 115)
3. Убедитесь что вопрос добавлен в избранное

## 6. Возможные проблемы и решения

### Проблема: "MODX context required"
**Решение:** Убедитесь что сниппет вызывается с восклицательным знаком: `[[!snippetName]]`

### Проблема: "Config file not found"
**Решение:** Проверьте что файл `config.core.php` существует в корне проекта

### Проблема: Не работают иконки Bootstrap Icons
**Решение:** Проверьте что в шаблоне `LMS_Bootstrap_5.tpl` есть строка:
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/bootstrap-icons.css" rel="stylesheet">
```

### Проблема: "CSRF token validation failed"
**Решение:** Убедитесь что файл `core/components/testsystem/bootstrap.php` подключается в начале сниппета

### Проблема: Не отображаются вопросы
**Решение:**
1. Проверьте что вопросы созданы и опубликованы (published = 1)
2. Проверьте что тест активен (is_active = 1)
3. Проверьте консоль браузера на ошибки JavaScript

## 7. Дополнительные возможности

### 7.1 Импорт вопросов из CSV

1. Откройте страницу теста
2. Нажмите "Импорт из CSV"
3. Загрузите файл CSV в формате:
```csv
Вопрос,Ответ 1,Ответ 2,Ответ 3,Ответ 4,Правильный ответ,Объяснение
"Вопрос 1","Ответ A","Ответ B","Ответ C","Ответ D","1","Объяснение"
```

### 7.2 Настройка прав доступа

1. Создайте группу ресурсов для защиты тестов
2. Назначьте права группам пользователей
3. Добавьте тесты в группу ресурсов

## 8. Техническая поддержка

Если возникли проблемы:

1. Проверьте логи MODX: `core/cache/logs/error.log`
2. Проверьте логи тестовой системы: `assets/components/testsystem/ajax/testsystem_errors.log`
3. Проверьте консоль браузера (F12 → Console)
4. Проверьте вкладку Network в браузере для AJAX запросов
