# Test System - Установка шаблона

Пошаговая инструкция по установке шаблона **TestSystem** с chunks.

---

## 📦 Что включено

### **Шаблон:**
- **TestSystem.tpl** - Основной шаблон страницы

### **Chunks:**
1. **tsHead** - Head секция (meta, CSS, стили)
2. **tsHeader** - Шапка сайта (навигация, меню пользователя)
3. **tsFooter** - Подвал сайта (ссылки, статистика, копирайт)
4. **tsScripts** - JS скрипты (Bootstrap, Test System JS, инициализация)

### **Особенности:**
- ✅ Bootstrap 5 интегрирован
- ✅ Font Awesome для иконок
- ✅ Адаптивный дизайн
- ✅ Геймификация (XP, уровни в шапке)
- ✅ Уведомления в реальном времени
- ✅ Статистика в подвале
- ✅ TV поля для дополнительного CSS/JS

---

## 🚀 Установка

### **Шаг 1: Выполнить SQL скрипт**

В phpMyAdmin выполните:

```sql
-- Файл: core/components/testsystem/sql/ADD_TESTSYSTEM_TEMPLATE.sql
```

Этот скрипт создаст:
- 4 chunks (tsHead, tsHeader, tsFooter, tsScripts)
- Шаблон TestSystem
- 2 TV поля (cssTV, jsTV)

### **Шаг 2: Загрузить содержимое из файлов**

На сервере выполните:

```bash
cd ~/mpv2.lmix.ru/public_html/core/components/testsystem
php update_template_chunks.php
```

Этот скрипт загрузит содержимое шаблона и всех chunks из файлов в базу данных.

### **Шаг 3: Очистить кеш MODX**

1. Войти в MODX Manager
2. **Управление → Очистить кеш**

## 📝 Использование

### **Создать страницу с шаблоном TestSystem**

1. В MODX Manager создать новый ресурс
2. Выбрать шаблон **TestSystem**
3. Заполнить контент
4. Сохранить и опубликовать

### **Пример контента страницы:**

```html
<div class="row">
    <div class="col-lg-8">

        [[!testsList?

    </div>

    <div class="col-lg-4">
        [[!leaderboardCompact?
            &limit=`5`
            &period=`weekly`
        ]]
    </div>
</div>
```

## 🎨 Настройка ID страниц

В chunks **tsHeader.tpl** и **tsFooter.tpl** используются ID страниц. **Замените их** на реальные ID ваших страниц:

### **В tsHeader.tpl:**

```php
{$_modx->makeUrl(999)}   // → ID страницы "Тесты"
{$_modx->makeUrl(1000)}  // → ID страницы "Обучение"
{$_modx->makeUrl(1001)}  // → ID страницы "Рейтинг"
{$_modx->makeUrl(1002)}  // → ID страницы "Избранное"
{$_modx->makeUrl(1003)}  // → ID страницы "Профиль"
{$_modx->makeUrl(1004)}  // → ID страницы "Мои результаты"
{$_modx->makeUrl(1005)}  // → ID страницы "Сертификаты"
{$_modx->makeUrl(1006)}  // → ID страницы "Вход"
{$_modx->makeUrl(1007)}  // → ID страницы "Регистрация"
```

### **Как узнать ID страницы:**
1. Открыть страницу в MODX Manager для редактирования
2. Посмотреть в адресной строке: `?a=resource/update&id=123`
3. Число после `id=` - это ID страницы

## 🔧 Дополнительные настройки

### **Добавить свой CSS**

1. Открыть страницу в MODX Manager
2. Вкладка **Template Variables**
3. Найти поле **cssTV**
4. Добавить CSS код:

```css
.my-custom-class {
    background: #f0f0f0;
    padding: 20px;
}
```

### **Добавить свой JS**

1. В том же месте найти поле **jsTV**
2. Добавить JS код:

```javascript
console.log('My custom JS loaded!');
```

## 🎯 Особенности шаблона

### **1. Автоматическое отображение XP и уровня**

В шапке автоматически показывается уровень и XP авторизованного пользователя:

```
⭐ Уровень 5 | 1250 XP
```

### **2. Уведомления в реальном времени**

Система автоматически проверяет новые уведомления каждые 30 секунд и показывает badge.

### **3. Адаптивное меню**

Меню автоматически сворачивается в "бургер" на мобильных устройствах.

### **4. Статистика в подвале**

Автоматически отображается статистика системы:
- Количество пользователей
- Количество тестов
- Количество прохождений
- Средний балл

### **5. Анимация карточек**

Карточки (.card) автоматически анимируются при появлении в области видимости.

## 🐛 Решение проблем

### **Проблема: Chunks не отображаются**

**Решение:**
1. Проверить что chunks созданы: **Элементы → Chunks**
2. Запустить `update_template_chunks.php` заново
3. Очистить кеш MODX

### **Проблема: Стили не применяются**

**Решение:**
1. Проверить путь к CSS: `/assets/components/testsystem/css/tsrunner.css`
2. Открыть файл в браузере напрямую - должен открываться
3. Проверить права на файлы (644)

### **Проблема: JS не работает**

**Решение:**
1. Открыть консоль браузера (F12) → Console
2. Проверить наличие ошибок
3. Убедиться что jQuery загружается раньше других скриптов

### **Проблема: Меню пользователя не показывается**

**Решение:**
1. Проверить что пользователь авторизован: `{$_modx->user.id}` должен быть > 0
2. Проверить snippet `getUserStats` установлен
3. Очистить кеш сессий MODX
