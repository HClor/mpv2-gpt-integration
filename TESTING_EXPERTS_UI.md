# Инструкция по тестированию UI управления экспертами

## Быстрый старт

### 1. Откройте страницу управления категориями
URL: `/upravlenie-kategoriyami` (ID: 185)

### 2. Проверьте наличие кнопки "Эксперты"
В таблице категорий для каждой категории должна быть кнопка **"Эксперты"** (синяя кнопка).

### 3. Откройте модальное окно
Нажмите кнопку **"Эксперты"** для любой категории.

### Что должно произойти:
- Открывается модальное окно "Управление экспертами: [Название категории]"
- Вверху раздел "Текущие эксперты" (сначала может быть пусто или "Загрузка...")
- Внизу раздел "Назначить эксперта" с формой

## Тест 1: Назначение эксперта

### Шаги:
1. В модальном окне найдите раздел "Назначить эксперта"
2. В выпадающем списке выберите эксперта (например, `expert1` или `expert2`)
3. Установите галочки на правах:
   - ✅ Управление тестами
   - ✅ Управление вопросами
   - ⬜ Подтверждение изменений (оставьте пустым для первого теста)
4. Нажмите кнопку **"Назначить эксперта"**

### Ожидаемый результат:
- Появится alert "Эксперт успешно назначен!"
- В разделе "Текущие эксперты" появится карточка эксперта с информацией:
  - Имя пользователя
  - Email
  - Права: "Тесты, Вопросы"
  - Дата назначения
  - Кнопка "Удалить" (красная)

## Тест 2: Проверка фильтрации экспертов

### Шаги:
1. После назначения первого эксперта откройте выпадающий список снова
2. Проверьте, что назначенный эксперт **исчез** из списка

### Ожидаемый результат:
- В выпадающем списке только те эксперты, которые еще не назначены
- Если назначить всех экспертов, появится "Нет доступных экспертов" и select будет disabled

## Тест 3: Назначение второго эксперта с другими правами

### Шаги:
1. Выберите другого эксперта из списка
2. Установите все три права:
   - ✅ Управление тестами
   - ✅ Управление вопросами
   - ✅ Подтверждение изменений
3. Нажмите **"Назначить эксперта"**

### Ожидаемый результат:
- В разделе "Текущие эксперты" теперь **две карточки**
- У второго эксперта права: "Тесты, Вопросы, Подтверждение"

## Тест 4: Удаление эксперта

### Шаги:
1. В карточке первого эксперта нажмите кнопку **"Удалить"**
2. Подтвердите удаление в диалоговом окне

### Ожидаемый результат:
- Появится alert "Эксперт успешно удален!"
- Карточка эксперта исчезнет из списка
- В выпадающем списке снова появится этот эксперт

## Тест 5: Повторное открытие модального окна

### Шаги:
1. Закройте модальное окно (кнопка "Закрыть" или крестик)
2. Откройте его снова для той же категории

### Ожидаемый результат:
- Данные загружаются заново
- Показываются актуальные назначенные эксперты
- Выпадающий список содержит только не назначенных экспертов

## Тест 6: Проверка нескольких категорий

### Шаги:
1. Закройте текущее модальное окно
2. Откройте модальное окно для **другой** категории
3. Назначьте эксперта на эту категорию

### Ожидаемый результат:
- Каждая категория имеет свой независимый список экспертов
- Один эксперт может быть назначен на несколько категорий

## Проверка в консоли браузера (F12)

## Возможные проблемы и решения

### Модальное окно не открывается
**Решение:** Проверьте, что Bootstrap JS загружен. Откройте консоль (F12) и посмотрите на ошибки.

### "Загрузка..." не исчезает
**Проблема:** API запрос не выполняется или возвращает ошибку.
**Решение:**
1. Откройте консоль (F12)
2. Перейдите на вкладку Network
3. Откройте модальное окно и посмотрите на запросы к `testsystem.php`
4. Проверьте ответ сервера

### Кнопка "Назначить эксперта" не работает
**Решение:** Проверьте консоль на ошибки JavaScript. Убедитесь, что файл `category-experts.js` загружен.

### Alert показывает ошибку
**Возможные причины:**
- Не выбран эксперт в списке
- CSRF токен невалиден (обновите страницу)
- Эксперт уже назначен (ошибка в фильтрации)
- Проблемы с правами доступа

## Проверка в базе данных

После назначения экспертов можно проверить в phpMyAdmin:

```sql
-- Посмотреть всех назначенных экспертов
SELECT
    ce.id,
    ce.category_id,
    c.name as category_name,
    u.username,
    ce.can_manage_tests,
    ce.can_manage_questions,
    ce.can_approve,
    ce.assigned_at
FROM modx_test_category_experts ce
JOIN modx_test_categories c ON c.id = ce.category_id
JOIN modx_users u ON u.id = ce.user_id
ORDER BY ce.assigned_at DESC;
```
