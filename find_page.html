SQL для поиска страницы /tests/list

Скопируйте и выполните в phpMyAdmin:

1. Поиск по alias "list" в папке "tests":

-- Сначала найдем папку tests
SELECT id, pagetitle, alias, template, content
FROM modx_site_content
WHERE alias = 'tests' OR alias = 'list';

2. Поиск всех страниц с алиасом "list":

SELECT
    c.id,
    c.pagetitle,
    c.alias,
    c.template,
    c.content,
    c.parent,
    p.pagetitle as parent_title,
    p.alias as parent_alias
FROM modx_site_content c
LEFT JOIN modx_site_content p ON p.id = c.parent
WHERE c.alias = 'list'
ORDER BY c.id;

3. Поиск по URI:

SELECT id, pagetitle, alias, uri, template, content
FROM modx_site_content
WHERE uri LIKE '%tests/list%' OR uri LIKE '%tests%'
ORDER BY uri;

4. Проверка контента страницы:

-- Замените ID_СТРАНИЦЫ на ID найденной страницы
SELECT id, pagetitle, content, template
FROM modx_site_content
WHERE id = ID_СТРАНИЦЫ;

После выполнения запросов:

  1. Найдите ID страницы /tests/list
  2. Посмотрите поле content - там должен быть вызов сниппета
  3. Если там НЕТ [[!myTests]], нужно его добавить
