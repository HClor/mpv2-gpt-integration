🗄️ Database Tests Check

SQL запросы для проверки

Скопируйте и выполните в phpMyAdmin:

1. Общее количество тестов:

SELECT COUNT(*) AS total_tests FROM modx_test_tests;

2. Все тесты с информацией о создателях:

SELECT
    t.id,
    t.title,
    t.created_by,
    u.username,
    t.publication_status,
    t.is_active,
    t.created_at,
    (SELECT COUNT(*) FROM modx_test_questions WHERE test_id = t.id) as questions_count
FROM modx_test_tests t
LEFT JOIN modx_users u ON u.id = t.created_by
ORDER BY t.created_at DESC
LIMIT 20;

3. Тесты по пользователям:

SELECT
    t.created_by,
    u.username,
    COUNT(*) as tests_count,
    SUM(CASE WHEN t.is_active = 1 THEN 1 ELSE 0 END) as active_tests
FROM modx_test_tests t
LEFT JOIN modx_users u ON u.id = t.created_by
GROUP BY t.created_by, u.username;

4. Проверка текущего пользователя:

-- Ваш userId = 2
SELECT * FROM modx_test_tests WHERE created_by = 2;

⚠️ Важно: Создание теста

Для создания теста перейдите на страницу /tests/list и нажмите кнопку "Создать тест"

После создания теста, вернитесь сюда и проверьте результат.

Возможные причины отсутствия тестов:

  1. База данных пустая - нужно создать первый тест
  2. Тесты созданы другим пользователем (не userId=2)
  3. Тесты помечены как is_active=0 (неактивные)
