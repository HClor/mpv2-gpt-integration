## 📖 КРИТЕРИИ УДАЛЕНИЯ

Файл должен быть **УДАЛЕН** если:

1. ❌ **Дублирование** - информация присутствует в других документах
2. ❌ **Устаревание** - дата создания > 30 дней назад и информация устарела
3. ❌ **Лишний** - описывает промежуточные этапы которые уже завершены
4. ❌ **Заменен** - есть более свежий документ на эту тему

Файл должен быть **ОСТАВЛЕН** если:

1. ✅ **Актуальность** - информация по-прежнему верна
2. ✅ **Уникальность** - информация не дублируется в других местах
3. ✅ **Полнота** - документ полностью описывает тему
4. ✅ **Важность** - документ нужен пользователям для работы с системой
