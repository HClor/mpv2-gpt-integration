# Тестовые скрипты (архив)

Эта папка содержит устаревшие тестовые скрипты и временные файлы, использовавшиеся во время разработки.

## Содержимое

### HTML тесты
- **test_api.html** - Тестирование API endpoints

### PHP тесты
- **test_learning_articles.php** - Тест учебных статей
- **test_phpspreadsheet.php** - Тест библиотеки PHPSpreadsheet
- **test_phpspreadsheet_debug.php** - Отладочная версия теста PHPSpreadsheet
- **API_CATEGORY_EXPERTS_NEW_METHODS.php** - Тестирование новых методов API экспертов

### SQL тесты
- **test_data_learning_paths.sql** - Тестовые данные для образовательных траекторий

## Статус

Все скрипты в этой папке считаются устаревшими и архивными.

Для текущего тестирования используйте:
- Актуальные unit-тесты в проекте
- [Руководство по отладке](../../guides/DEBUGGING_GUIDE.md)
- Официальные инструменты тестирования MODX
