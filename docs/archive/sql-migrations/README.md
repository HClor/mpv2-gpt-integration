# SQL миграции (архив)

Эта папка содержит устаревшие SQL скрипты миграций и исправлений, которые были выполнены во время разработки.

## Содержимое

- **fix_existing_tests_publication_status.sql** - Исправление статуса публикации существующих тестов
- **migrate_to_categories_system.sql** - Миграция на систему категорий

## Статус

Все миграции выполнены и применены к базе данных.
Эти файлы сохранены для истории и документации изменений.
