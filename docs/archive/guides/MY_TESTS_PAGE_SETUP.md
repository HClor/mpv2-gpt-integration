# Настройка страницы "Мои тесты"

## 📖 Обзор

Страница "Мои тесты" позволяет пользователям:
- ✅ Видеть свои созданные тесты (включая приватные)
- ✅ Видеть тесты, к которым им предоставлен доступ
- ✅ Просматривать публичные тесты
- ✅ Создавать новые тесты
- ✅ Управлять доступом к приватным тестам

---

## 🚀 Создание страницы в MODX

### Шаг 1: Создать ресурс

1. Откройте панель управления MODX: `https://ваш-сайт.ru/manager/`
2. В дереве ресурсов нажмите правой кнопкой мыши на родительской категории
3. Выберите **"Создать" → "Создать ресурс здесь"**

### Шаг 2: Заполнить основные поля

**Во вкладке "Документ":**

| Поле | Значение |
|------|----------|
| **Заголовок страницы** | `Мои тесты` |
| **Псевдоним (alias)** | `my-tests` или `moi-testy` |
| **Шаблон** | Выберите шаблон вашей LMS системы (обычно тот же, что у других тестовых страниц) |
| **Опубликован** | ✅ Да |
| **Меню** | ✅ Да (если хотите показывать в меню) |

### Шаг 3: Добавить вызов сниппета

**В поле "Содержимое ресурса"** вставьте:

```
[[!myTests]]
```

> **Важно:** Используйте `[[!myTests]]` с восклицательным знаком, чтобы сниппет НЕ кэшировался. Это необходимо для отображения актуальных данных пользователя.

### Шаг 4: Настроить права доступа (опционально)

Если вы хотите, чтобы страница была доступна только авторизованным пользователям:

1. Перейдите во вкладку **"Права доступа"**
2. Добавьте группу пользователей (например, "Authenticated")
3. Установите минимальную роль (например, "Member")

### Шаг 5: Сохранить

Нажмите **"Сохранить"** в правом верхнем углу.

## 📂 Структура страницы

После создания страница будет иметь 3 вкладки:

### 1. Вкладка "Созданные мной"

**Что показывается:**
- Все тесты, созданные текущим пользователем
- Включая приватные тесты
- Включая черновики

**Кнопки управления:**
- **Редактировать** - открыть тест для прохождения/редактирования
- **Импорт** - импортировать вопросы из CSV/Excel
- **Настройки** - изменить название, описание, тайминги
- **👥 Управление доступом** - предоставить/отозвать права (только для приватных тестов)
- **🌐 Публикация** - изменить статус: черновик → приватный → unlisted → публичный
- **🗑️ Удалить** - удалить тест

**Пример отображения:**
```
┌─────────────────────────────────────────────────────┐
│ 🔒 Тест по JavaScript (Приватный)                   │
│ 15 вопросов · Создан: 01.12.2024                    │
│ [Редактировать] [Импорт] [👥 Доступ] [Удалить]      │
└─────────────────────────────────────────────────────┘
```

---

### 2. Вкладка "Доступны мне"

**Что показывается:**
- Тесты, к которым пользователю предоставлен доступ через систему разрешений
- Только тесты с `can_view = 1`
- Только если не истек срок доступа (`expires_at IS NULL OR expires_at > NOW()`)

**Бейджи прав:**
- 👁️ **Просмотр** - может только проходить тест
- ✏️ **Редактирование** - может редактировать вопросы и настройки

**Пример отображения:**
```
┌─────────────────────────────────────────────────────┐
│ Тест по SQL                                          │
│ Владелец: admin · 20 вопросов                        │
│ [✏️ Редактирование] [Пройти тест]                    │
└─────────────────────────────────────────────────────┘
```

---

### 3. Вкладка "Публичные"

**Что показывается:**
- Все тесты со статусом `publication_status = 'public'`
- Доступны всем пользователям системы

**Кнопки:**
- **Пройти тест** - начать прохождение

**Пример отображения:**
```
┌─────────────────────────────────────────────────────┐
│ 🌐 Тест по HTML/CSS                                  │
│ Автор: Иван Петров · 25 вопросов                     │
│ [Пройти тест]                                        │
└─────────────────────────────────────────────────────┘
```

## 🔗 Добавление в меню навигации

### Вариант 1: Автоматически через MODX

Если вы отметили "Показывать в меню" при создании ресурса, страница появится в меню автоматически.

### Вариант 2: Прямая ссылка

Добавьте ссылку в ваш шаблон или навигацию:

```html
<a href="/my-tests" class="nav-link">
    <i class="bi bi-folder"></i> Мои тесты
</a>
```

Или используйте MODX тег:

```
<a href="[[~123]]" class="nav-link">Мои тесты</a>
```

*(где 123 - ID ресурса "Мои тесты")*

## 🎨 JavaScript и стили

Сниппет автоматически подключает необходимые файлы:

**JavaScript:**
- `/assets/components/testsystem/js/mytests.js` - логика работы с тестами, API вызовы

**Стили:**
- Используется Bootstrap 5 (убедитесь что он подключен в вашем шаблоне)
- Иконки Bootstrap Icons (для значков 🔒, 👥, 🗑️ и т.д.)

### Проверка зависимостей в шаблоне

Убедитесь что в `<head>` вашего шаблона подключены:

```html
<!-- Bootstrap 5 CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap Icons -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.10.0/font/bootstrap-icons.css" rel="stylesheet">
```

И перед закрывающим `</body>`:

```html
<!-- Bootstrap 5 JS -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
```

## 🧪 Проверка работы

### 1. Для владельца теста

1. Войдите как эксперт или админ
2. Откройте `/my-tests`
3. Нажмите **"Создать тест"**
4. Создайте приватный тест
5. Убедитесь что тест появился во вкладке **"Созданные мной"**
6. Нажмите **👥 Управление доступом**
7. Найдите пользователя и предоставьте ему права

### 2. Для пользователя с доступом

1. Войдите как обычный пользователь
2. Откройте `/my-tests`
3. Перейдите во вкладку **"Доступны мне"**
4. Убедитесь что тест виден с бейджем "Просмотр" или "Редактирование"
5. Пройдите тест

### 3. Для всех пользователей

1. Откройте `/my-tests`
2. Перейдите во вкладку **"Публичные"**
3. Убедитесь что видны все публичные тесты

## 📊 API эндпоинты (для справки)

Страница использует следующие API методы:

| Метод | Описание |
|-------|----------|
| `getMyTests` | Получить тесты созданные пользователем |
| `getSharedWithMe` | Получить тесты с предоставленным доступом |
| `getPublicTests` | Получить публичные тесты |
| `createTest` | Создать новый тест |
| `updateTestSettings` | Обновить настройки теста |
| `deleteTest` | Удалить тест |
| `grantTestAccess` | Предоставить доступ пользователю |
| `revokeTestAccess` | Отозвать доступ |
| `getTestPermissions` | Получить список пользователей с доступом |
| `changePublicationStatus` | Изменить статус публикации |

Все запросы идут на `/assets/components/testsystem/ajax/testsystem.php`

## 🆘 Решение проблем

### Проблема: "Для управления тестами необходимо войти в систему"

**Решение:** Пользователь не авторизован. Необходимо войти в систему.

### Проблема: Страница пустая или показывает ошибки JavaScript

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте что `mytests.js` загружается без ошибок
3. Проверьте что Bootstrap 5 подключен

### Проблема: Вкладка "Доступны мне" пустая

**Решение:**
1. Убедитесь что владелец теста предоставил вам доступ
2. Проверьте что доступ не истек (`expires_at`)
3. Проверьте в БД: `SELECT * FROM modx_test_permissions WHERE user_id = ВАШ_ID`

### Проблема: Не могу создать тест

**Решение:**
1. Проверьте права доступа (нужна роль эксперта или выше)
2. Проверьте консоль браузера на ошибки
3. Убедитесь что CSRF токен генерируется (проверьте `<meta name="csrf-token">`)

## 📝 Примечания

1. **Кэширование:** Используйте `[[!myTests]]` с восклицательным знаком, иначе данные будут закэшированы и пользователи увидят одинаковый контент
2. **Обновление данных:** При изменении прав доступа пользователю нужно обновить страницу (F5)
3. **Мобильная версия:** Интерфейс адаптивный и работает на мобильных устройствах
4. **Производительность:** При большом количестве тестов (>100) рекомендуется добавить пагинацию
