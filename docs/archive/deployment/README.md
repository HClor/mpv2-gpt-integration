# Файлы развертывания (архив)

Эта папка содержит устаревшие скрипты и файлы развертывания.

## Содержимое

- **deploy.sh** - Устаревший bash скрипт развертывания
- **install_logout_handler.php** - Установочный скрипт обработчика выхода из системы
- **testsystem-v2.0-deployment.tar.gz** - Архив развертывания версии 2.0
- **ht.access** - Дубликат файла .htaccess (резервная копия)

## Статус

Все файлы в этой папке устарели и заменены актуальными процедурами.

## Актуальные процедуры развертывания

Для текущего развертывания используйте:
- [Руководство по быстрому старту](../../guides/QUICKSTART.md)
- [Руководство по установке MODX](../../guides/MODX_INSTALLATION_GUIDE.md)
- [Руководство по настройке прав доступа](../../guides/DEPLOYMENT_GUIDE_PERMISSIONS.md)

## Примечания

- **deploy.sh** содержит устаревшую логику развертывания
- **install_logout_handler.php** заменен на актуальный метод (см. [LOGOUT_FIX_INSTALLATION.md](../../guides/LOGOUT_FIX_INSTALLATION.md))
- **testsystem-v2.0-deployment.tar.gz** сохранен для истории версий
