# Диагностические скрипты (архив)

Эта папка содержит устаревшие диагностические и отладочные скрипты, которые использовались во время разработки и тестирования системы.

## Содержимое

### Проверки базы данных (check_*)
- **check_db.html** - HTML интерфейс для проверки БД
- **check_knowledge_areas_table.sql** - Проверка таблицы областей знаний
- **check_modx_resources.sql** - Проверка ресурсов MODX
- **check_private_tests_system.sql** - Проверка системы приватных тестов
- **check_roles_and_permissions.sql** - Проверка ролей и прав доступа
- **check_table_structure.php** - PHP скрипт для проверки структуры таблиц
- **check_tests.sql** - Проверка тестов

### Диагностика (diagnose_*, diagnostic_*)
- **diagnose-manage-categories.php** - Диагностика управления категориями
- **diagnose_duplicate_scripts.html** - Поиск дублирующихся скриптов
- **diagnostic_learningMaterialsTemplate.php** - Диагностика шаблонов учебных материалов
- **diagnostic_learning_paths.php** - Диагностика образовательных траекторий

### Утилиты диагностики (diagnostics_*)
- **diagnostics_browser_console.js** - Консольные утилиты для браузера
- **diagnostics_categories.sql** - SQL диагностика категорий
- **diagnostics_experts_assignment.js** - Диагностика назначения экспертов
- **diagnostics_modx_console.php** - Консольные утилиты MODX
- **diagnostics_phpmyadmin.sql** - SQL запросы для phpMyAdmin
- **quick_diagnostics.js** - Быстрая диагностика

## Статус

Все скрипты в этой папке считаются устаревшими и архивными.

Для текущей диагностики и отладки используйте:
- [Руководство по отладке](../../guides/DEBUGGING_GUIDE.md)
- Логи системы в MODX
- Встроенные инструменты разработчика
