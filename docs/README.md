# docs/

Утилиты для работы с БД и архивная документация.

## SQL-утилиты

| Файл | Назначение |
|------|-----------|
| `modx_lms_export_queries.sql` | SQL-запросы для экспорта структуры и данных БД |
| `detailed_modx_analysis.sql` | Подробный анализ всех аспектов БД |
| `export_modx_lms_db.sh` | Bash-скрипт для автоматического экспорта БД |

## Архив

В `archive/` перенесена вся детальная документация, которая была актуальна на этапе разработки:
- Гайды по установке и настройке
- Аудиты архитектуры и кода
- Технические задания (ТЗ)
- Отчёты по рефакторингу
- Диагностические скрипты

Ключевая информация из этих файлов консолидирована в корневых файлах:
- **[../ARCHITECTURE.md](../ARCHITECTURE.md)** — архитектура, схема БД, API
- **[../DEVELOPMENT_RULES.md](../DEVELOPMENT_RULES.md)** — правила, ошибки, решения
