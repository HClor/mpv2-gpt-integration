# Просмотр неопубликованных учебных материалов

## Описание функциональности

Эта функциональность позволяет авторам, экспертам и администраторам просматривать неопубликованные учебные материалы (черновики) до их публикации.

## Основные возможности

### 1. Вкладки на странице учебных материалов

Для пользователей с правами создания материалов (Администраторы и Эксперты) на главной странице "Учебные материалы" (ID: 149) отображаются две вкладки:

- **Опубликованные** - материалы с статусом `published = 1`
- **Черновики** - материалы с статусом `published = 0`

### 2. Визуальная индикация статуса

Каждый материал отображается с соответствующим бейджем:
- 🟢 **Опубликован** - зеленый бейдж для опубликованных материалов
- ⚪ **Черновик** - серый бейдж для неопубликованных материалов

### 3. Просмотр черновиков

**Механизм просмотра:**
- Черновики открываются в модальном окне (не как отдельная страница)
- Загрузка содержимого происходит через AJAX
- Проверка прав доступа выполняется на уровне API

**Кто может просматривать черновики:**
- Автор материала
- Администраторы
- Пользователи с ролью "Эксперт"

**Обычные пользователи:**
- Видят только вкладку "Опубликованные"
- Не имеют доступа к черновикам

   - Использует существующий API endpoint `getMaterial` для загрузки данных

### Как это работает

#### Список материалов
1. При загрузке страницы учебных материалов, сниппет `learningArticles` вызывается дважды:
   - Один раз с параметром `showDrafts=false` для вкладки "Опубликованные"
   - Один раз с параметром `showDrafts=true` для вкладки "Черновики"

2. Сниппет выполняет SQL-запрос с условием:
   ```php
   // Для опубликованных
   'published' => 1

   // Для черновиков
   'published' => 0
   ```

3. Для опубликованных материалов отображается кнопка-ссылка "Читать"
4. Для черновиков отображается кнопка "Просмотр" с обработчиком `viewDraftMaterial()`

#### Просмотр черновика через AJAX
1. Пользователь кликает на кнопку "Просмотр" у черновика
2. JavaScript вызывает функцию `viewDraftMaterial(materialId)`
3. Функция делает AJAX-запрос к API endpoint `getMaterial`:
   ```javascript
   const result = await apiCall('getMaterial', { material_id: materialId });
   ```
4. API проверяет права доступа:
   ```php
   $canEdit = $isAuthenticated &&
              ((int)$resource->get('createdby') === $userId || $isAdmin || $isExpert)
   ```
5. Если права есть, API возвращает данные материала (включая содержимое)
6. JavaScript заполняет модальное окно и отображает его

#### Преимущества AJAX-решения
- ✅ **Не требует установки плагинов** - работает "из коробки"
- ✅ **Использует существующий API** - endpoint `getMaterial` уже был реализован
- ✅ **Простая установка** - достаточно обновить файлы, нет ручной настройки
- ✅ **Безопасность** - проверка прав на уровне API
- ✅ **Удобство** - быстрый просмотр без перехода на другую страницу

## Использование

### Создание черновика

1. Перейдите на страницу "Учебные материалы"
2. Нажмите кнопку **"Создать материал"**
3. Заполните форму:
   - Название материала
   - Краткое описание
   - Категория (опционально)
   - Содержимое
4. **НЕ ВКЛЮЧАЙТЕ** переключатель "Опубликовать материал"
5. Нажмите "Сохранить"
6. Материал появится во вкладке **"Черновики"**

### Просмотр черновиков

1. Перейдите на страницу "Учебные материалы"
2. Переключитесь на вкладку **"Черновики"**
3. Вы увидите список своих неопубликованных материалов (или всех черновиков, если вы админ/эксперт)
4. Нажмите **"Просмотр"** для просмотра черновика
5. Откроется модальное окно с содержимым
6. В модальном окне доступны кнопки:
   - **"Закрыть"** - закрыть окно просмотра
   - **"Редактировать"** - перейти к редактированию черновика

### Публикация черновика

#### Способ 1: Из модального окна просмотра
1. Откройте черновик для просмотра (кнопка "Просмотр")
2. Нажмите **"Редактировать"** в модальном окне
3. Включите переключатель **"Опубликовать материал"**
4. Нажмите "Сохранить"
5. Материал переместится из вкладки "Черновики" во вкладку "Опубликованные"

#### Способ 2: Прямое редактирование
1. Во вкладке "Черновики" нажмите иконку карандаша (редактировать)
2. Включите переключатель **"Опубликовать материал"**
3. Нажмите "Сохранить"

## Проверка прав доступа

### Автор материала
- Видит свои черновики во вкладке "Черновики"
- Может открывать и читать свои черновики
- Может редактировать и публиковать свои черновики
- **НЕ видит** черновики других авторов (если не является админом/экспертом)

### Администратор
- Видит ВСЕ черновики во вкладке "Черновики"
- Может открывать и читать любые черновики
- Может редактировать и публиковать любые черновики

### Эксперт
- Видит ВСЕ черновики во вкладке "Черновики"
- Может открывать и читать любые черновики
- Может редактировать и публиковать любые черновики

### Обычный пользователь
- НЕ видит вкладку "Черновики"
- Видит только опубликованные материалы
- Не может получить доступ к черновикам через API (проверка прав)

## Возможные проблемы и решения

### Проблема: Не вижу вкладку "Черновики"

**Причина:** У вас нет прав на создание материалов

**Решение:**
- Вкладка "Черновики" отображается только для Администраторов и Экспертов
- Попросите администратора добавить вас в группу "Expert"

### Проблема: При клике на "Просмотр" ничего не происходит

**Причины и решения:**

1. **JavaScript не загрузился:**
   - Откройте консоль браузера (F12)
   - Проверьте наличие ошибок JavaScript
   - Очистите кэш браузера (Ctrl+F5)

2. **Отсутствует CSRF токен:**
   - Проверьте, что в HTML есть `<meta name="csrf-token" content="...">`
   - Обновите страницу

3. **Проблемы с API:**
   - Откройте консоль браузера (F12) → вкладка Network
   - Кликните "Просмотр" и проверьте запрос к `testsystem.php`
   - Проверьте ответ сервера на наличие ошибок

### Проблема: Модальное окно пустое или показывает ошибку

**Причина:** API вернул ошибку или нет прав доступа

**Решение:**
1. Проверьте в консоли браузера (F12) текст ошибки
2. Убедитесь, что вы являетесь автором черновика или имеете права админа/эксперта
3. Проверьте, что материал существует и не удален

### Проблема: Вижу чужие черновики (для обычных авторов)

**Причина:** Вы имеете роль Администратора или Эксперта

**Решение:**
- Это нормальное поведение для Администраторов и Экспертов
- Если вы обычный автор, проверьте свои права в MODX Manager
