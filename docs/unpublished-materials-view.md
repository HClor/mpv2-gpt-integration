# Просмотр неопубликованных учебных материалов

## Описание функциональности

Эта функциональность позволяет авторам, экспертам и администраторам просматривать неопубликованные учебные материалы (черновики) до их публикации.

## Основные возможности

### 1. Вкладки на странице учебных материалов

Для пользователей с правами создания материалов (Администраторы и Эксперты) на главной странице "Учебные материалы" (ID: 149) отображаются две вкладки:

- **Опубликованные** - материалы с статусом `published = 1`
- **Черновики** - материалы с статусом `published = 0`

### 2. Визуальная индикация статуса

Каждый материал отображается с соответствующим бейджем:
- 🟢 **Опубликован** - зеленый бейдж для опубликованных материалов
- ⚪ **Черновик** - серый бейдж для неопубликованных материалов

### 3. Доступ к черновикам

**Кто может просматривать черновики:**
- Автор материала
- Администраторы
- Пользователи с ролью "Эксперт"

**Обычные пользователи:**
- Видят только вкладку "Опубликованные"
- Не имеют доступа к черновикам

## Технические детали

### Измененные файлы

1. **`/core/elements/snippets/learningMaterialsTemplate.php`**
   - Добавлены вкладки Bootstrap для переключения между опубликованными и черновиками
   - Условная логика отображения вкладок в зависимости от прав пользователя

2. **`/core/elements/snippets/learningArticles.php`**
   - Добавлен параметр `showDrafts` (boolean)
   - Фильтрация материалов по статусу `published`
   - Отображение соответствующих бейджей статуса
   - Разные сообщения для пустых списков опубликованных/черновиков

3. **`/core/elements/plugins/allowDraftMaterialsAccess.php`** (НОВЫЙ)
   - Плагин для разрешения доступа к неопубликованным страницам
   - Срабатывает на событие `OnPageNotFound`
   - Проверяет права пользователя перед предоставлением доступа

### Установка плагина (ОБЯЗАТЕЛЬНО!)

Для работы функциональности просмотра черновиков необходимо установить плагин:

1. Войдите в MODX Manager
2. Перейдите в раздел **Элементы → Плагины**
3. Создайте новый плагин с именем **AllowDraftMaterialsAccess**
4. Скопируйте содержимое файла `/core/elements/plugins/allowDraftMaterialsAccess.php`
5. Подпишите плагин на системное событие: **OnPageNotFound**
6. Сохраните и активируйте плагин

**Без установки этого плагина черновики будут видны в списке, но при попытке их открыть будет показана ошибка 404!**

### Как это работает

#### Список материалов
1. При загрузке страницы учебных материалов, сниппет `learningArticles` вызывается дважды:
   - Один раз с параметром `showDrafts=false` для вкладки "Опубликованные"
   - Один раз с параметром `showDrafts=true` для вкладки "Черновики"

2. Сниппет выполняет SQL-запрос с условием:
   ```php
   // Для опубликованных
   'published' => 1

   // Для черновиков
   'published' => 0
   ```

#### Доступ к черновикам
1. Когда пользователь кликает на черновик, MODX пытается загрузить неопубликованную страницу
2. По умолчанию MODX возвращает 404 для неопубликованных страниц
3. Плагин `AllowDraftMaterialsAccess` перехватывает событие `OnPageNotFound`
4. Плагин проверяет:
   - Существует ли ресурс?
   - Это учебный материал (template=6)?
   - Это черновик (published=0)?
   - Пользователь имеет права (автор/админ/эксперт)?
5. Если все проверки пройдены, плагин разрешает доступ

## Использование

### Создание черновика

1. Перейдите на страницу "Учебные материалы"
2. Нажмите кнопку **"Создать материал"**
3. Заполните форму:
   - Название материала
   - Краткое описание
   - Категория (опционально)
   - Содержимое
4. **НЕ ВКЛЮЧАЙТЕ** переключатель "Опубликовать материал"
5. Нажмите "Сохранить"
6. Материал появится во вкладке **"Черновики"**

### Просмотр черновиков

1. Перейдите на страницу "Учебные материалы"
2. Переключитесь на вкладку **"Черновики"**
3. Вы увидите список своих неопубликованных материалов
4. Кликните **"Читать"** для просмотра черновика
5. При необходимости нажмите **"Редактировать материал"** для внесения изменений

### Публикация черновика

1. Откройте черновик для просмотра или редактирования
2. Нажмите **"Редактировать материал"**
3. Включите переключатель **"Опубликовать материал"**
4. Нажмите "Сохранить"
5. Материал переместится из вкладки "Черновики" во вкладку "Опубликованные"
6. Теперь его смогут видеть все пользователи

## Проверка прав доступа

### Автор материала
- Видит свои черновики во вкладке "Черновики"
- Может открывать и читать свои черновики
- Может редактировать и публиковать свои черновики
- **НЕ видит** черновики других авторов

### Администратор
- Видит ВСЕ черновики во вкладке "Черновики"
- Может открывать и читать любые черновики
- Может редактировать и публиковать любые черновики

### Эксперт
- Видит ВСЕ черновики во вкладке "Черновики"
- Может открывать и читать любые черновики
- Может редактировать и публиковать любые черновики

### Обычный пользователь
- НЕ видит вкладку "Черновики"
- Видит только опубликованные материалы
- При прямом доступе к URL черновика получает 404

## Возможные проблемы и решения

### Проблема: При клике на черновик показывается 404

**Причина:** Плагин `AllowDraftMaterialsAccess` не установлен или не активирован

**Решение:**
1. Проверьте, что плагин создан в MODX Manager
2. Убедитесь, что плагин подписан на событие `OnPageNotFound`
3. Убедитесь, что плагин активирован (checkbox "Enabled")
4. Очистите кэш MODX

### Проблема: Не вижу вкладку "Черновики"

**Причина:** У вас нет прав на создание материалов

**Решение:**
- Вкладка "Черновики" отображается только для Администраторов и Экспертов
- Попросите администратора добавить вас в группу "Expert"

### Проблема: Вижу чужие черновики

**Это нормальное поведение для Администраторов и Экспертов**

Если вы обычный автор, но видите чужие черновики - проверьте свои права в системе.

## Безопасность

- Черновики защищены проверкой прав на уровне PHP
- Неавторизованные пользователи не могут получить доступ к черновикам
- Плагин логирует каждый доступ к черновику в лог MODX
- Прямой доступ к URL черновика без прав приводит к 404

## Совместимость

- MODX Revolution 2.x
- Bootstrap 5.x (для вкладок)
- Требуется роль "Expert" в системе
- Требуется Template ID = 6 для учебных материалов
