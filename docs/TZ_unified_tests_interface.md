# ТЗ: Унификация интерфейса тестов - объединение categoriesAndTests и testRunner

## 1. Проблема

### Текущее состояние:
- **categoriesAndTests** (страница `/testy`, ID: 35) - отображает категории и список тестов
- **testRunner** (страница `/test-run`, ID: 45) - промежуточная страница с интерфейсами управления тестом

### Проблемы текущей реализации:
1. **404 ошибки при запуске тестов**
   - Ссылки формируются как `/test?sessionId=X` (404)
   - Должны быть `/test-run?sessionId=X`

2. **Пустая страница после закрытия модального окна настроек**
   - URL: `/test-run?testId=106&view=manage`
   - При закрытии модалки остается пустая страница (test-info скрыт)

3. **Избыточность промежуточных страниц**
   - Пользователь переходит: Тесты → test-run → действие
   - Нужно: Тесты → действие (без промежуточного экрана)

## 2. Цель

**Объединить функциональность categoriesAndTests и testRunner на одной странице без промежуточных переходов.**

Пользователь должен:
- Видеть список тестов с категориями
- Запускать тесты напрямую (Тренировка/Экзамен)
- Редактировать вопросы
- Управлять настройками теста
- Удалять тесты

**ВСЁ на одной странице** `/testy` без переходов на `/test-run`.

## 3. Требования

### 3.1. Страница категорий и тестов (`/testy`)

#### Основной интерфейс:
- Левая колонка: список категорий
- Правая колонка: карточки тестов текущей категории
- Поиск по названию теста
- Пагинация (20 тестов на страницу)

#### Карточка теста должна содержать:
1. **Название теста** и **описание**
2. **Метаинформация:**
   - Количество вопросов
   - Проходной балл
   - Время на экзамен
3. **Контролы запуска (для всех пользователей):**
   - Поле ввода количества вопросов (только для тренировки)
   - Кнопка "Все" (устанавливает макс. количество вопросов)
   - Кнопка "Тренировка"
   - Кнопка "Экзамен"
4. **Выпадающее меню ⋮ (только для владельцев/админов/экспертов):**
   - Импорт вопросов
   - Редактировать вопросы
   - Настройки теста
   - Удалить тест

### 3.2. Функциональность на странице `/testy`

#### 3.2.1. Запуск теста (Тренировка/Экзамен)
**Поведение:**
1. Кликаем "Тренировка" или "Экзамен"
2. AJAX запрос к API `startSession`
3. **Редирект на `/test-run?sessionId=X`** (НЕ `/test`)
4. Начинается прохождение теста

**Важно:** Проверить правильность URL для редиректа!

#### 3.2.2. Импорт вопросов
**Поведение:**
1. Кликаем "Импорт вопросов"
2. Переход на страницу импорта `/import-csv-page?test_id=X`

#### 3.2.3. Редактировать вопросы
**Поведение:**
1. Кликаем "Редактировать вопросы"
2. **НЕ уходим со страницы `/testy`**
3. Скрываем список тестов и категорий
4. Показываем интерфейс редактирования вопросов (тот же, что в testRunner)
5. **Кнопка "Назад к списку тестов"** - возвращает к списку тестов

**Компоненты интерфейса редактирования:**
- Заголовок теста
- Фильтры (Все, Опубликовано, Не опубликовано, В обучении)
- Кнопка "Добавить вопрос"
- Список вопросов с кнопками действий
- **Контролы запуска теста** (поле количества, Все, Тренировка, Экзамен)
- **Кнопка "Назад к списку тестов"**

#### 3.2.4. Настройки теста
**Поведение:**
1. Кликаем "Настройки теста"
2. **НЕ уходим со страницы `/testy`**
3. Открывается модальное окно управления тестом
4. После закрытия модалки остаемся на странице `/testy` (список тестов видим)

**Важно:** Модальное окно должно открываться поверх списка тестов, а не на пустой странице!

#### 3.2.5. Удалить тест
**Поведение:**
1. Кликаем "Удалить тест"
2. Подтверждение
3. AJAX запрос к API `deleteTest` с CSRF токеном
4. Перезагрузка страницы `/testy`

### 3.3. Технические требования

#### 3.3.1. Страница `/testy` (categoriesAndTests)
**Файлы:**
- `core/elements/snippets/categoriesAndTests.php`
- `assets/components/testsystem/js/test-cards.js`
- `assets/components/testsystem/css/categories-and-tests.css`

**Функциональность:**
1. Отображение категорий и тестов
2. **Встроенный интерфейс редактирования вопросов** (скопировать из testRunner)
3. **Встроенное модальное окно настроек** (скопировать из testRunner)
4. **Встроенное модальное окно добавления вопроса** (скопировать из testRunner)
5. Запуск тестов через API с редиректом на `/test-run?sessionId=X`

#### 3.3.2. Страница `/test-run` (testRunner)
**Назначение:** Только для прохождения теста и работы с sessionId

**Функциональность (сохранить):**
1. Прохождение теста с sessionId
2. Отображение вопросов
3. Таймер (для экзамена)
4. Отправка ответов
5. Результаты теста

**Функциональность (УБРАТЬ):**
1. Выбор режима (Тренировка/Экзамен) - больше не нужен
2. Интерфейс редактирования вопросов - переносим в categoriesAndTests
3. Модальное окно настроек - переносим в categoriesAndTests
4. Модальное окно добавления вопроса - переносим в categoriesAndTests

#### 3.3.3. CSRF Protection
**Обязательно:**
```php
// В categoriesAndTests.php
$modx->getRequest();  // Инициализация сессии
$output = CsrfProtection::getTokenMeta();
```

```javascript
// В test-cards.js
const csrfToken = document.querySelector('meta[name="csrf-token"]')?.content;
requestData.data.csrf_token = csrfToken;
```

#### 3.3.4. URL редиректа при запуске теста
**ВАЖНО:** Проверить все места, где формируется URL для редиректа после запуска сессии:

```javascript
// ❌ НЕПРАВИЛЬНО
window.location.href = '/test?sessionId=' + sessionId;

// ✅ ПРАВИЛЬНО
window.location.href = '/test-run?sessionId=' + sessionId;
```

**Места для проверки:**
1. `test-cards.js` - функция `startTestSession()`
2. `tsrunner.js` - функция `startTestFromQuestions()`
3. Любые другие места с `startSession` API

#### 3.3.5. Состояние после закрытия модальных окон
**Настройки теста:**
1. Модальное окно открывается на странице `/testy`
2. После закрытия - возвращаемся к списку тестов (НЕ пустая страница)

**Редактирование вопросов:**
1. Интерфейс открывается на странице `/testy`
2. Кнопка "Назад к списку тестов" возвращает к списку

## 7. Ожидаемый результат

### 7.1. Пользовательский опыт

**Обычный пользователь (студент):**
1. Заходит на `/testy`
2. Видит список тестов по категориям
3. Выбирает количество вопросов (или "Все")
4. Нажимает "Тренировка" или "Экзамен"
5. **Сразу начинается тест** (переход на `/test-run?sessionId=X`)

**Владелец/Эксперт/Админ:**
1. Заходит на `/testy`
2. Видит список тестов с выпадающим меню ⋮
3. Может:
   - **Редактировать вопросы** - открывается интерфейс НА ЭТОЙ ЖЕ странице
   - **Настроить тест** - открывается модальное окно НА ЭТОЙ ЖЕ странице
   - **Импортировать вопросы** - переход на `/import-csv-page`
   - **Удалить тест** - AJAX запрос, перезагрузка `/testy`
4. После любого действия возвращается к списку тестов на `/testy`

### 7.2. Технический результат

1. **Одна точка входа:** `/testy` для всех операций с тестами
2. **Нет промежуточных страниц:** все действия выполняются на месте
3. **Быстрая работа:** нет лишних переходов и загрузок
4. **Правильные URL:** `/test-run?sessionId=X` для прохождения
5. **CSRF защита:** работает везде
