# Диагностика отсутствия статей на странице "Учебные материалы"

## Проблема
На странице "Учебные материалы" (ID: 149) отображаются вопросы из тестов, но не отображаются учебные статьи.

## Шаги для диагностики

### 1. Проверка наличия сниппета в MODX

**В консоли MODX выполните:**
```php
$snippet = $modx->getObject('modSnippet', ['name' => 'learningArticles']);
if ($snippet) {
    return "✓ Сниппет learningArticles найден (ID: " . $snippet->get('id') . ")";
} else {
    return "✗ Сниппет learningArticles НЕ НАЙДЕН - нужно создать!";
}
```

**Если сниппет не найден, создайте его:**
1. Откройте: Элементы → Сниппеты
2. Нажмите "Создать сниппет"
3. Название: `learningArticles`
4. Код: скопируйте содержимое из файла `/core/elements/snippets/learningArticles.php`
5. Сохраните

### 2. Проверка наличия дочерних ресурсов

**В консоли MODX выполните:**
```php
$resources = $modx->getCollection('modResource', [
    'parent' => 149,
    'published' => 1,
    'deleted' => 0
]);

$output = "Найдено дочерних ресурсов: " . count($resources) . "\n\n";

if (count($resources) > 0) {
    foreach ($resources as $res) {
        $output .= "ID: " . $res->get('id') . "\n";
        $output .= "Название: " . $res->get('pagetitle') . "\n";
        $output .= "Published: " . ($res->get('published') ? 'Да' : 'Нет') . "\n";
        $output .= "Hidden: " . ($res->get('hidemenu') ? 'Да' : 'Нет') . "\n";
        $output .= "---\n";
    }
} else {
    $output .= "✗ Дочерних ресурсов НЕ НАЙДЕНО!\n";
    $output .= "Нужно создать хотя бы одну учебную статью как дочерний ресурс страницы 149.\n";
}

return $output;
```

**Если дочерних ресурсов нет, создайте тестовую статью:**
1. Откройте страницу "Учебные материалы" (ID: 149) в админке
2. Правый клик → "Создать" → "Создать документ здесь"
3. Заполните:
   - Название: `Тестовая статья`
   - Контент: любой текст
   - Шаблон: 6 (или тот же что у страницы 149)
   - Published: ✓ Да
4. Сохраните

### 3. Проверка TV поля category_id

**В консоли MODX выполните:**
```php
$tv = $modx->getObject('modTemplateVar', ['name' => 'category_id']);
if ($tv) {
    return "✓ TV поле category_id найдено (ID: " . $tv->get('id') . ")";
} else {
    return "⚠ TV поле category_id не найдено - материалы будут в разделе 'Без категории'";
}
```

**Если хотите создать TV поле:**
1. Откройте: Элементы → Переменные шаблона
2. Нажмите "Создать переменную шаблона"
3. Заполните:
   - Название: `category_id`
   - Тип ввода: Список (menu)
   - Возможные значения: оставьте пустым (будет заполняться динамически)
4. Привяжите к шаблону 6
5. Сохраните

### 4. Очистка кэша

**В админке MODX:**
1. Нажмите на шестеренку в правом верхнем углу
2. Выберите "Очистить кэш"
3. Подтвердите

**Или в консоли:**
```php
$modx->cacheManager->refresh();
return "✓ Кэш очищен";
```

### 5. Просмотр отладочной информации

После выполнения шагов выше:
1. Откройте страницу "Учебные материалы" на сайте
2. В секции "Учебные статьи" должна появиться синяя плашка с отладочной информацией:
   - Root Page ID: 149
   - Найдено дочерних ресурсов: X
   - Список найденных ресурсов

Это поможет понять, в чем проблема.

### 6. Отключение отладки

После того как всё заработает, отключите отладку:
1. Откройте файл `/core/elements/snippets/learningArticles.php`
2. Найдите строку: `$debugMode = true;`
3. Измените на: `$debugMode = false;`
4. Сохраните

## Наиболее вероятные причины

1. **Сниппет не создан в MODX** - файл есть, но сниппет не зарегистрирован в БД
2. **Нет дочерних ресурсов** - у страницы 149 нет опубликованных дочерних документов
3. **Кэш не очищен** - MODX показывает старую версию страницы

## Результаты тестирования

✓ Файл сниппета существует: `/core/elements/snippets/learningArticles.php`
✓ Сниппет вызывается в `learningMaterialsTemplate.php`
? Сниппет зарегистрирован в БД: **нужно проверить**
? Есть дочерние ресурсы у страницы 149: **нужно проверить**
